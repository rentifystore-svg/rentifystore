# Rentify - App Demo Landing Page

## 🚀 Project Overview

Rentify is a rental marketplace platform landing page featuring an interactive app demo with iPhone 15 frame showcase.

## 📁 Project Structure

```
new-project/
├── README.md           # Project documentation
├── index.html          # Main HTML file with app demo
└── assets/             # Images and assets
    └── images/         # App screenshot images
        ├── screen1.png  # Splash screen
        ├── screen2.png  # Onboarding 1
        ├── screen3.png  # Onboarding 2
        ├── screen4.png  # Onboarding 3
        ├── screen5.png  # Login/Signup
        ├── screen6.png  # Home screen
        ├── screen7.png  # Map screen
        ├── screen8.png  # Listing screen
        ├── screen9.png  # Chat screen
        └── screen10.png # Profile screen
```

## 🎯 Features

- **Hero Section**: Compelling headline with search functionality
- **App Demo**: Interactive iPhone 15 frame with 10-screen slideshow
- **Image Slider**: Automatic fade transitions (1s fade, 3s hold per screen)
- **Waitlist Form**: Phone number collection with validation
- **Responsive Design**: Fully responsive across all devices
- **Modern UI**: Clean, professional design with Tailwind CSS

## 🛠️ Technologies

- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework (CDN)
- **Vanilla JavaScript**: Image slider and form handling
- **Netlify**: Form submission ready

## � Getting Started

1. **Replace placeholder images**: Add your actual app screenshots to `/assets/images/`
2. **Open in browser**: Launch `index.html` to view the landing page
3. **Test functionality**: Verify image slider and waitlist form work correctly
4. **Deploy**: Upload to your hosting platform
